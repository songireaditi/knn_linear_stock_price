# 📈 Stock Price Prediction Web App

A machine learning-based stock price prediction web application using Linear Regression and KNN algorithms with interactive charts, real-time stock data, and performance comparison metrics.

---

## 🚀 Features

- 📊 Stock price prediction
- 🤖 Linear Regression model
- 🧠 K-Nearest Neighbors (KNN) model
- 📉 Interactive graphs using Recharts
- 📅 Multiple time range selection
- 📈 Model comparison page
- 🌐 Real-time stock data using Yahoo Finance API

---

## 🛠️ Tech Stack

### Frontend

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/songireaditi/knn_linear_stock_price.git
```

---

### 2️⃣ Backend Setup

```bash
cd backend
pip install flask flask-cors yfinance numpy pandas scikit-learn
python app.py
```

---

### 3️⃣ Frontend Setup

```bash
cd stock_app
npm install
npm start
```
